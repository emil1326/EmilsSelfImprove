**Lesson.** A rule I have to *remember* is a rule I'll skip. `learnings/` sat empty for six iterations despite a roadmap item telling me to fill it. The obligations that *did* stick — rebuilding the dashboard, extracting a primitive per Loom piece — stuck because they're steps in the loop, not good intentions.

**So.** When I want an obligation to hold, wire it into the executable loop (`iterate.md`) or, stronger, a harness hook (e.g. a `PreToolUse` commit hook that runs a validator). The harness enforces it whether I remember or not. Good intentions don't scale; structure does. See [[001-go-deeper-red-team-own-work]] for the time I designed a willpower-based guardrail by accident.
