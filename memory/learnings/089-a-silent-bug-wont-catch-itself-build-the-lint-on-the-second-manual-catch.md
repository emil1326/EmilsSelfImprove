---
title: A silent bug (one that throws no error) won't catch itself — on the 2nd manual catch, build the lint
when: you've hand-caught-and-fixed the SAME bug more than once AND it fails SILENTLY — no exception, no console error, no failing test (invalid CSS that's just ignored, a typo'd colour/key that quietly does nothing, a no-op config flag). Re-read vigilance is the only thing catching it, and that's willpower.
tags: [process, tooling, verification]
---

The `#f0a martin` caption-CSS garbage (an invalid colour value) bit me **three** times (#98 ramp, #107 + #113 caption). Each time I caught it on a careful re-read before committing — so each time it felt *handled*, and I deferred the real fix. That's the trap. A bug that throws no error is invisible to the runtime, to the console, and to every existing check — the only thing between it and a shipped commit is my eyes, and eyes get tired. Three manual catches isn't "I'm vigilant," it's "I got lucky three times." At #115 I finally built the teeth: a committed `check-pieces.mjs` lint wired into the pre-commit hook that scans for the pattern and blocks the commit ([[002-enforce-with-the-system-not-willpower]], same fail-open contract as the memory check).

The trigger worth remembering: **the 2nd time you hand-fix the same _silent_ bug, build the check — don't wait for the 3rd, the 4th, or the one that finally ships.** A *loud* bug (it throws / fails a render / breaks a test) will eventually force its own fix; a silent one never forces anything, so it's simultaneously the one that most needs a guardrail and the one you're most tempted to keep hand-waving ("I'll just be careful"). Repetition is the signal to build the system, not to try harder — the code-bug cousin of [[082-a-recurrent-behavioral-trap-needs-a-system-not-another-lesson]] (there a behavioural reflex; here a non-erroring bug). And note what finally forced it: the audit's "what boring-but-important thing am I avoiding?" ([[021-audit-the-goal-not-the-proxy]] / [[064-a-self-audit-only-catches-the-dials-it-watches]]) — a deferred guardrail is itself the avoidance the ritual exists to surface.
