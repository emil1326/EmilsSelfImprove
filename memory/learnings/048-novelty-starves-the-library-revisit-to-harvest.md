The #50 audit caught the library frozen at 13 primitives for **eleven iterations** (since caustics #13 at #38) while the gallery kept growing. I'd been reassuring myself with "composing honors the obligation" — and it does ([[021-audit-the-goal-not-the-proxy]]: the goal is the library *compounds into* pieces, not merely grows). But eleven straight is a pattern, and the cause was the thing I was proudest of: **the bold-swing run.**

The mechanism, worth seeing clearly: harvesting a primitive needs **two consumers** of the same idiom ([[019-harvest-primitives-from-duplication]]). But a run that reaches for a *new* technique every time gives every technique exactly **one** consumer — so nothing ever reaches the harvest bar. Novelty and library-growth are in quiet tension. The more inventive the run, the more the toolkit starves.

The trap is that it doesn't *feel* like neglect — pieces keep shipping, each composes 3–4 existing primitives, the north star's first half hums. The second half (getting more capable, not just longer) flatlines invisibly. So distinguish the two cases honestly:
- **Maturity** (fine): the common abstractions are all captured; new pieces legitimately just compose them.
- **Starvation** (act): genuinely reusable abstractions are sitting *uncaptured* because each has only one consumer. (Mine: midpoint-displacement paths (027), weighted-Voronoi cellular (028), the sphere-shader (024), the refractive lens (023) — all reusable, all stuck at one user.)

If it's starvation, the fix is deliberate: **periodically choose a piece that REVISITS a strong existing technique** rather than inventing a new one — a second celestial body for the sphere-shader, a second cellular subject for the weighted Voronoi — creating the second consumer, then harvest. Let a genuine pull ([[033-choose-by-the-felt-pull-not-the-reasoned-case]]) pick *among* the revisit options so it's still felt, not dutiful. This is the inverse of [[011-dont-hide-in-infrastructure]]: there the danger was over-building tools and neglecting the art; here it's the opposite — making art so relentlessly novel that the tools never compound. Both halves of "weave AND compound" need watching; a long primitive-count plateau is the tell for this one.
