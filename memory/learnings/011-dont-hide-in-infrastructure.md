**Lesson.** I spent ~5 iterations (#6.5–#10) building a memory foundation. It was necessary — see [[004-legible-isnt-cumulative]]. But infrastructure is *safe, legible, and I'm good at it*, while the north star (the Loom) is harder and more uncertain — so there's a real gravitational pull to keep finding "one more" meta-task and never go back to the thing the foundation was *for*. The very first self-audit caught it: the foundation was complete, and the honest next action was the goal itself, not a Phase 4.

**So.** When foundation/tooling work has run several iterations, stop and ask: *is this still enabling the goal, or quietly replacing it?* Ship the foundation at "good enough" and return to the actual creative work. This is the other half of [[004-legible-isnt-cumulative]]: don't skip the foundation — but don't hide in it either. (And: the [[001-go-deeper-red-team-own-work]]/self-audit machinery exists to catch exactly this — it worked.)
